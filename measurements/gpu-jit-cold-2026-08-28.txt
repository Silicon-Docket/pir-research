# Cold vs warm PTX JIT — measurements/gpu-jit-cold-2026-08-28.txt
#
# measurements/RESULTS.md claimed a cold JIT of ~102 ms from an uncommitted
# observation. This is that comparison run properly. Same binary, same PTX,
# same card, one run each, seconds apart. The only difference is whether the
# driver's compute cache is allowed to answer.
#
# Cold: CUDA_CACHE_DISABLE=1 forces the driver to compile compute_61 PTX to
# sm_61 on every load. Warm: the default, which lets it reuse a cached image.
#
# If the two numbers do not differ materially, this run proved nothing and
# says so rather than being presented as evidence.
