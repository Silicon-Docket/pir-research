CAP terms of use — verbatim capture
====================================

Captured : 2026-08-28
Source   : https://case.law/terms/
Method   : that page is a JavaScript module and its raw HTML contains none of
           this text — which is why an earlier attempt concluded the wording
           "could not be captured verbatim". It is in the Lit template bundle.
           Reproduce with:

               curl -s https://case.law/templates/cap-terms-page.js

           then strip the markup. Neither the page HTML nor static.case.law's
           index contains the words "CC0", "public domain" or "creative
           commons"; the bundle does.

Why this file exists
--------------------
LICENSES.md recorded CAP's status as "Partly — CC0 asserted by mirrors, not
yet read verbatim from case.law/terms", and the corpus analysis called that the
single highest-priority open item because the whole Pro thesis rests on it.
This closes it against the source rather than against a mirror.

What it settles, and what it does not
-------------------------------------
SETTLED: the caselaw data *and metadata* are CC0 1.0. This prototype reads only
metadata (CasesMetadata.json), so it is squarely inside that grant, and so is
commercial use.

NOT a licence condition, but worth honouring: the Community Norms request
attribution to Harvard and the Caselaw Access Project "to the extent it is
technologically feasible". Harvard is explicit that these are requests and that
it does not impose legally binding conditions. Cheap to honour; a product
decision rather than a legal one.

DOES NOT APPLY: the CC BY-SA 4.0 below governs the *text of the case.law site*,
not the data. Do not carry it into anything about the corpus.
